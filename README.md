# Trading App

A full-stack algorithmic and paper trading application with FastAPI backend, interactive dashboard, and **Graphify** codebase knowledge graph integration.

## Project Structure

```
trading-app/
├── trading_app/
│   ├── core/           # Configuration and settings
│   ├── models/         # Pydantic data models
│   ├── services/       # Business logic (market data, execution, portfolio, strategies, backtest)
│   ├── api/            # FastAPI routers
│   └── static/         # Frontend dashboard
├── tests/              # Pytest test suite
├── graphify-out/       # Graphify knowledge graph outputs (generated)
└── .agents/            # Antigravity rules & workflows (generated by graphify)
```

## Setup

```powershell
# Install dependencies
uv sync

# Run the server
uv run uvicorn trading_app.main:app --reload --port 8000
```

Then open http://localhost:8000 in your browser.

## Running Tests

```powershell
uv run pytest tests/ -v
```

## Graphify Knowledge Graph

```powershell
# Install Graphify for Antigravity
graphify antigravity install

# Extract AST + code graph (no API key needed)
graphify extract . --code-only

# View architectural hubs
graphify god-nodes

# Query the graph
graphify query "How does order execution update portfolio balances?"

# Generate interactive graph visualization
graphify export html
graphify tree

# Rebuild graph after code changes
.\run_graphify.ps1
```

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/v1/portfolio` | Current portfolio state |
| GET | `/api/v1/market/quote/{ticker}` | Get live quote |
| GET | `/api/v1/market/candles/{ticker}` | Get OHLCV candles |
| POST | `/api/v1/orders` | Place a new order |
| GET | `/api/v1/orders` | Order history |
| POST | `/api/v1/backtest` | Run a strategy backtest |

## Paper Trading

The paper trading engine simulates real market conditions with:
- Configurable slippage (default 5 bps)
- Commission fees (default 0.1% per trade)
- \$100,000 starting cash balance

## Strategies

- **SMA Crossover**: Golden/death cross signals using short/long SMA windows
- **RSI Mean Reversion**: Overbought/oversold RSI signals (default 30/70 thresholds)
